## 🚀 Getting Started

### Local Preview
Because this is pure HTML5 + Tailwind CSS + Vanilla JS, simply open `index.html` in any modern web browser or serve via any static web server:

```bash
# Using Python
python3 -m http.server 8080

# Using Node / npx
npx serve .
```
